# Sistema de guardias

Aplicación web para administrar los **turnos de guardias**, hecha con **ASP.NET Web Forms** y **MySQL**.

## Funciones

- Registrar guardias con trabajador, turno, inicio y fin del turno y observaciones.
- Editar, reemplazar y dar de baja ("se va") a un guardia.
- Mantener el orden de rotación de los turnos.

## Configuración

En `Guardias/Web.config`, completar la cadena de conexión a MySQL (`pwd=TU_CLAVE`).

## Cómo ejecutarlo

Abrir `Guardias.sln` en Visual Studio y ejecutar con F5.

## Tecnologías

C#, ASP.NET Web Forms, MySQL (MySql.Data).
